# Experiment 5: Geo-Visualization with Maps

## Objective
To visualize location-based data using maps in Power BI.

## Software
Microsoft Power BI Desktop

## Procedure
1. Import a dataset containing country, state, or city information and a numeric measure.
2. Set the location column's data category appropriately, such as Country/Region, State, or City.
3. Add a Map visual to the report.
4. Place the location field in the Location field well.
5. Place a numeric measure, such as Sales or Cases, in the Size field well.
6. Format the map and verify that locations are displayed correctly.
7. Save the report as `Experiment5_GeoVisualization.pbix`.

## Output
A Power BI map showing geographic data by location.
