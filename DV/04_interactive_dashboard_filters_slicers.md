# Experiment 4: Interactive Dashboards with Filters and Slicers

## Objective
To build an interactive retail dashboard in Power BI using filters and slicers.

## Software
Microsoft Power BI Desktop

## Procedure
1. Import a retail dataset into Power BI.
2. Create charts showing sales by region and category.
3. Add a slicer for Region.
4. Add a slicer for Category.
5. Add a date slicer using the Order Date field.
6. Check that the slicers filter the report visuals.
7. Arrange the visuals into a dashboard-style report page.
8. Save the report as `Experiment4_InteractiveDashboard.pbix`.

## Output
An interactive Power BI report with region, category, and date slicers.
