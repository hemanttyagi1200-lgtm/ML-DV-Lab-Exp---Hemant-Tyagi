# Experiment 2: Data Cleaning and Transformation

## Objective
To clean and transform a dataset using Power Query in Power BI.

## Software
Microsoft Power BI Desktop

## Procedure
1. Open Power BI Desktop and import a CSV dataset.
2. Select Transform Data to open Power Query Editor.
3. Identify missing or blank values.
4. Remove or replace missing values where appropriate.
5. Rename columns to meaningful names.
6. Set the correct data type for each column.
7. Create a calculated column if required.
8. Select Close & Apply to load the transformed data.
9. Save the report as `Experiment2_DataCleaning.pbix`.

## Output
A cleaned and transformed dataset loaded into Power BI.
