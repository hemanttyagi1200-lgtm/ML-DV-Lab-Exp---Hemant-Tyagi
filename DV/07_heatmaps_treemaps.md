# Experiment 7: Heatmaps and Tree Maps

## Objective
To create a heatmap for a correlation matrix and a treemap for category-wise sales in Power BI.

## Software
Microsoft Power BI Desktop

## Procedure
1. Import a dataset containing numeric fields and category/subcategory fields.
2. Create a correlation matrix using suitable numeric fields.
3. Apply conditional formatting to represent correlation values with colors.
4. Add a Treemap visual.
5. Place Category and Subcategory in the Group fields.
6. Place Sales or another numeric measure in Values.
7. Review the color intensity and size of each category.
8. Save the report as `Experiment7_HeatmapsTreemaps.pbix`.

## Output
A Power BI report showing a correlation heatmap and a category-wise treemap.
