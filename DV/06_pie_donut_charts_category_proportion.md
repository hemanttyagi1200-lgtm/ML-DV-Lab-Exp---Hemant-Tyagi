# Experiment 6: Pie and Donut Charts for Category Proportion

## Objective
To display category proportions using pie and donut charts in Power BI.

## Software
Microsoft Power BI Desktop

## Procedure
1. Import a dataset containing categories and numeric values.
2. Add a Pie Chart visual.
3. Place the category field in Legend and the numeric measure in Values.
4. Add a Donut Chart visual using the same fields.
5. Enable data labels or percentages where appropriate.
6. Compare the proportions represented by each category.
7. Save the report as `Experiment6_PieDonutCharts.pbix`.

## Output
A Power BI report containing pie and donut charts showing category proportions.
