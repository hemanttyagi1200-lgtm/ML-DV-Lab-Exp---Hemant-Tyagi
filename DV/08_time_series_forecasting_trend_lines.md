# Experiment 8: Time Series Forecasting and Trend Lines

## Objective
To analyze time-based data in Power BI using trend lines, moving averages, and forecasting.

## Software
Microsoft Power BI Desktop

## Procedure
1. Import a dataset containing a date field and a numeric measure, such as sales or stock prices.
2. Create a Line Chart with the date field on the X-axis and the numeric measure on the Y-axis.
3. Set the X-axis to a continuous date axis if appropriate.
4. Add a trend line or moving average using a supported visual or suitable DAX calculation.
5. If forecasting is available for the chart and data, open the Analytics pane and configure a forecast.
6. Review the trend and forecast results.
7. Save the report as `Experiment8_TimeSeriesForecasting.pbix`.

## Output
A Power BI report showing a time-series line chart with trend analysis and, where supported, a forecast.
