# Experiment 1: Getting Started with Power BI

## Objective
To import a CSV dataset into Power BI and explore basic table, bar, and line charts.

## Software
Microsoft Power BI Desktop

## Procedure
1. Open Power BI Desktop.
2. Select Get Data and import a CSV dataset.
3. Load the data.
4. Create a table visual.
5. Create a bar chart to compare categories.
6. Create a line chart to show trends over time.
7. Save the report as `Experiment1_GettingStarted.pbix`.

## Output
A Power BI report containing a table, bar chart, and line chart.
