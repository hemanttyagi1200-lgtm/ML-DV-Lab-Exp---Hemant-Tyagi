# Experiment 3: Bar and Line Charts for Series Data

## Objective
To create bar and line charts in Power BI to compare categories and display trends over time.

## Software
Microsoft Power BI Desktop

## Procedure
1. Import a sales or stock-market dataset into Power BI.
2. Create a Clustered Bar Chart.
3. Add a category field to the Y-axis and a numeric field to the X-axis.
4. Create a Line Chart.
5. Add a date field to the X-axis and a numeric field to the Y-axis.
6. Add data labels and tooltips where appropriate.
7. Save the report as `Experiment3_BarLineCharts.pbix`.

## Output
A Power BI report containing a bar chart for category comparison and a line chart for trends over time.
